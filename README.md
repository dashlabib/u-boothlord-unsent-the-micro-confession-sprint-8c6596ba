A two-part micro-confession, 177 characters: a "To:" line naming who it was meant for — my best friend from school — and the unsent line itself, 146 characters, admitting a betrayal the writer can never tell the one person who trusts them completely. The program reads the confession from `entry.txt`, checks it rule by rule against the bounty gate (UTF-8, 1–260 characters, exactly two parts with a "To:" line and one message line of at most 200 characters, no trailing space, no control characters), and publishes it byte for byte to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
